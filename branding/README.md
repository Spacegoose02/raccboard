# Raccboard brand

A geometric raccoon head with three kanban cards on its forehead: the raccoon sorts things into columns.

## Files

| File | Use |
|---|---|
| `raccboard-logo.svg` | Primary logo (mark + wordmark) on light backgrounds |
| `raccboard-logo-dark.svg` | Same, for dark backgrounds |
| `raccboard-mark.svg` | Raccoon mark alone, transparent background |
| `raccboard-icon.svg` | App icon / favicon: mark on a navy rounded square |
| `png/` | PNG exports: icon at 16–1024 px, mark at 256–1024 px, logos at 1760 px wide |

The wordmark in the SVGs uses live text (Inter, falling back to Segoe UI / Helvetica / Arial). Use the PNGs where exact lettering matters.

## Colors

| Name | Hex | Use |
|---|---|---|
| Navy | `#1E2A3A` | Icon background, wordmark on light |
| Fur | `#3A404A` | Raccoon head |
| Mask | `#14171C` | Mask, pupils, nose |
| Cloud | `#E8ECF1` | Eyes, muzzle, inner ears, wordmark on dark |
| Teal | `#2DD4BF` | Kanban cards, accent on dark |
| Teal deep | `#14B8A6` | "board" in the wordmark on light |

## Usage

- Keep clear space around the logo of at least the height of the kanban cards.
- Use `raccboard-icon` below 48 px; the bare mark loses its ears on busy backgrounds.
- Don't recolor the mask, stretch the mark, or set the wordmark in another typeface.
