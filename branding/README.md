# Raccboard brand

A friendly flat raccoon (round ears, bandit mask, white muzzle) peeking over a kanban board, in the same style as the sun raccoon icon.

## Files

| File | Use |
|---|---|
| `raccboard-logo.svg` | Primary logo (mark + wordmark) on light backgrounds |
| `raccboard-logo-dark.svg` | Same, for dark backgrounds |
| `raccboard-mark.svg` | Raccoon mark alone, transparent background |
| `raccboard-icon.svg` | App icon / favicon: mark on a navy rounded square |
| `png/` | PNG exports: icon at 16–1024 px, mark at 256–1024 px, logos at 1720 px wide |

The wordmark in the SVGs uses live text (Nunito, falling back to other rounded or system fonts). Use the PNGs where exact lettering matters.

## Usage

- Keep clear space around the logo of at least the height of the kanban cards.
- Use `raccboard-icon` below 48 px; the bare grey mark gets lost on light grey backgrounds.
- Don't recolor the mask, stretch the mark, or set the wordmark in another typeface.
